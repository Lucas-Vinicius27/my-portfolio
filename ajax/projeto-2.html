Student Workspace

Sobre o projeto:

Aplicação web de produtividade baseada na técnica Pomodoro, desenvolvida como TCC do curso de Ciência da Computação na UNIP, com login pelo Firebase Authentication e dados salvos no Cloud Firestore.

Detalhes:

  • Cliente:Projeto acadêmico (TCC)
  • Tecnologias:Next.js, React, TypeScript, Firebase Authentication e Cloud Firestore
  • Categoria:Front End
  • Data:2021 - 2023
  • URL:github.com/Lucas-Vinicius27/student-workspace
